# 🎬 Screenmatch

O **Screenmatch** é um projeto desenvolvido durante meus estudos de **Java e Spring Boot na Alura**.

O projeto faz parte dos cursos da formação **Java Back-end** da Alura e tem como objetivo colocar em prática conceitos importantes do desenvolvimento Java, especialmente persistência de dados, Spring Boot e acesso a banco de dados.

## 📚 Sobre o projeto

Durante o desenvolvimento do Screenmatch, estou acompanhando as aulas e desafios propostos pela **Alura**, utilizando o projeto como ambiente de aprendizado e prática.

Ao longo do curso, o projeto é utilizado para trabalhar conceitos como:

* Java e Programação Orientada a Objetos
* Spring Boot
* Spring Data JPA
* Hibernate
* PostgreSQL
* Mapeamento de entidades
* Relacionamentos entre entidades
* Repositories
* Persistência e consulta de dados
* Streams e Lambdas
* Consumo e manipulação de dados

## 🛠️ Tecnologias utilizadas

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* PostgreSQL
* Maven
* IntelliJ IDEA
* Git / GitHub

## 🎯 Objetivo

O principal objetivo deste projeto é **aprendizado e prática**.

O Screenmatch está sendo desenvolvido como parte dos meus estudos na plataforma **Alura**, seguindo o conteúdo apresentado durante o curso e implementando os exercícios, funcionalidades e desafios propostos.

Além de acompanhar as aulas, utilizo o projeto para reforçar os conceitos estudados e experimentar pequenas alterações por conta própria.

## 📖 Origem

Projeto educacional desenvolvido durante a formação de **Java Back-end da Alura**.

Os conceitos, estrutura inicial e desafios do projeto são baseados no material apresentado nos cursos da plataforma.
